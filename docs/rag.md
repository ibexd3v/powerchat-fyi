Powerchat allows you to create per-folder RAG databases, which can be used to share context across chats in the same folder.

# RAG

## tl;dr
- Create a chat folder
- Enable RAG for the folder in Folder Settings
- (Optional) Set API key for the embedder
- (Optional) Tweak RAG parameters
- (Optional) Add documents to the RAG from "RAG Documents" option in the folder's toolbar
